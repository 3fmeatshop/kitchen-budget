HOME KITCHEN BUDGET – Android app (APK)

GitHub builds the APK automatically every time you upload files.
1. Open the repository on GitHub > Actions tab > "Build Android APK" (wait for a green check, about 5 minutes).
2. Open the repository main page > Releases (right side) > newest "Kitchen Budget v1.x".
3. On your phone, tap KitchenBudget.apk to download, then open it and tap Install.
   (Allow "Install unknown apps" for Chrome if asked. If Play Protect warns, tap More details > Install anyway.)

Updating: upload the new index.html. GitHub builds a new version. Download it from Releases and tap Install;
it updates over the old app and keeps your data.

Your data stays on the phone. Use Budgets > Download backup now and then; the file is saved in Downloads/KitchenBudget.
